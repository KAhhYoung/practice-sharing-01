기본필수를 끝낸 뒤 선택합니다. 코드는 여전히 실습당 한 파일이며 **사용자 정의 함수·클래스·예외처리를 추가하지 않습니다.** 입력을 `data/`, 결과를 `outputs/`에 두는 것부터 연습합니다. TODO는 8곳입니다.

## 열 폴더와 실행 위치

VS Code에서 `수강생용/02_응용`을 엽니다. 모든 아래 명령은 **`02_응용` 폴더의 터미널** 기준입니다. 기존 수업 환경을 사용하고 패키지 문제는 [전체 안내](../README.md)를 따릅니다.

```text
02_응용/
├─ README.md
├─ 01_xy.py … 07_project.py
├─ data/
│  └─ requests.csv             # 원본 입력; 이동·덮어쓰기 하지 않음
└─ outputs/                    # 처음에는 비어 있음
   └─ valid_predictions.csv    # 07 실행으로 생성
```

경로 처리 코드는 제공했습니다. 예를 들어 `HERE / "data" / "requests.csv"`는 이 Python 파일이 있는 위치 아래의 데이터 파일을 뜻합니다. 새로운 보조 모듈은 만들지 않습니다.

## 사용할 데이터

| 열 | 의미 | 역할 |
|---|---|---|
| `request_id` | 요청을 구분하는 ID | 결과를 연결할 때 사용, 모델 입력에서는 제외 |
| `input_chars` | 요청 입력의 글자 수 | 입력 X |
| `allowed_tools` | 요청 전에 정한 사용 가능 도구 수 | 입력 X |
| `task_type` | 작업 종류 | 입력 X |
| `priority` | 요청 전에 정한 우선순위 | 입력 X |
| `failed` | 실패 1 / 성공 0 | 분류의 정답 y |
| `status` | 실행이 끝난 뒤의 상태 | 실행 전 예측의 입력에서는 제외 |
| `elapsed_ms` | 실제 실행시간(ms) | 실행 전 입력에서는 제외. 회귀 문제의 정답으로는 사용 가능 |
| `retry_count` | 실행 중 발생한 재시도 수 | 실행 전 입력에서는 제외 |

결측은 대체 방법을 배우기 위해 의도적으로 포함했습니다. 손상된 파일, 중복 ID, 잘못된 데이터 형식 처리 과제는 넣지 않았습니다. `requests.csv`는 원본으로 보관하고, 생성한 결과만 `outputs/`에 저장합니다.

원본은 PPT와 같은 100건입니다. 두 번의 `random_state=42` 분할로 train 60·valid 20·test 20을 유지합니다. 숫자 두 열과 범주형 두 열은 총 8열로 변환됩니다. 02·05는 원리를 확인하기 위한 작은 표를 코드 안에서 만듭니다.
